# Raunak Singh — Personal Portfolio & Production Systems

> **"I design, research, and build digital experiences that make complex things feel simple."**

A world-class, production-grade personal portfolio website for **Raunak Singh**, Computer Science & Design undergraduate (Class of 2028), UX researcher, and product builder. Currently shaping digital experiences at **ITC Limited** (Foods Division, Bengaluru).

---

## ✦ Creative & Technical Highlights

- **Aesthetic Direction**: Editorial, minimal, sophisticated, typography-first Swiss international style. Deep Obsidian `#0C0D0E`, Electric Vermilion `#FF4D29`, and hairline typographic grids.
- **Flagship Case Study**: *ITC Limited — Rethinking Inventory Management on the Factory Floor* (30+ worker interviews, 10+ leadership deep-dives, 30K+ transactional records analyzed, low-cognitive-load floor ergonomics).
- **Interactive Verification Simulators**:
  - `ITCFactoryScanner`: Rugged handheld laser barcode simulator with switchable Sunlight/Dim Bay lighting modes, 64px glove-friendly targets, and error prevention states.
  - `PropPandaSimulator`: Multilingual conversational AI real-estate assistant with inline generative luxury property cards and live broker intent radar.
  - `CIALabsQRSimulator`: Campus QR peer discovery handshake with interest-guessing gamification and WCAG AAA accessibility contrast mode.
  - `LlunaRoleSwitcher`: Cross-role academic platform with real-time vector search capstone duplicate detection.
  - `RNKTVConsoleSimulator`: 10-foot living room TV dashboard with keyboard arrow / D-pad focus spring physics and glanceable couch ergonomics.
- **Performance & Craft**: Built with Next.js 14 App Router, TypeScript, Tailwind CSS, and Framer Motion. Zero layout shifts, accessible contrast, semantic HTML, and responsive across mobile, tablet, and desktop breakpoints.

## ✦ Getting Started

```bash
# Install dependencies
npm install

# Run the local development server (default port 3005)
npm run dev -- -p 3005

# Build for production
npm run build

# Start production server
npm run start -p 3005
```

Open [http://localhost:3005](http://localhost:3005) in your browser.
